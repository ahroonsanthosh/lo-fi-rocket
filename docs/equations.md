# Equations register

Every physics equation implemented in this repository is listed here, per CLAUDE.md section 4.
An equation that is not in this register must not be in the code.

**Current phase:** v1.0 (all five phases and the v1.0 completion prompt); see `README.md`, `docs/known-limitations.md` and `docs/future-work.md`.
**Current task:** simulate anything (plan 0055, D-083): import never refuses (task 4 part 2; plan 0070, D-106 and D-107, pod sets: the physics, then the design file and the `.ork` reader; plan 0071, D-108, the comparison mode's base and rail button drag; plan 0073, D-110, each part's surface finish in the skin friction). The last addition is GEO-18. The last additions are UNIT-12 and UNIT-13 (plan 0062, SI prefixes and km/h).

Source abbreviations: **USSA76** = NOAA/NASA/USAF, _U.S. Standard Atmosphere, 1976_ (`reference/docs/ussa1976-nasa-ntrs-19770009539.pdf`; printed page numbers; PDF page = printed + 16 in Part 1, printed + 15 in the tables). **SI9** = BIPM, _The International System of Units (SI)_, 9th edition 2019 (`reference/docs/si-brochure-9-en.pdf`). **N09** = Niskanen (2009), _Development of an Open Source model rocket simulation software_ (`reference/docs/niskanen-2009-openrocket-thesis.pdf`; printed page numbers; PDF page = printed + 10). **NIST SP 811** = Thompson and Taylor, _Guide for the Use of the International System of Units (SI)_, NIST Special Publication 811, 2008 (`reference/docs/nist-sp811-2008.pdf`; printed page numbers; PDF page = printed + 12 in Appendix B).

## How to add an entry

1. Give the equation a stable ID: a short group prefix and a number (`ATM-3`, `BAR-12`, `DRAG-7`). IDs are never reused or renumbered.
2. Quote the source precisely: author, year, title, and the section, equation number, table or page in the source's own numbering.
3. State the validity range exactly as the source states it, plus any extra restriction imposed by our implementation.
4. List every symbol with its SI unit.
5. Name the implementing function as `packages/<pkg>/src/<path>.ts#functionName` and the test file that verifies it with a hand-calculated value.
6. Put the same citation in a comment directly above the implementation.

## Register

Test files are in the same folder as the implementation unless stated. "Verified by" names the test group that checks the entry against a hand calculation, a closed form or a published table (CLAUDE.md 7.1 and 7.2).
