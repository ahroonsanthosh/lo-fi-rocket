# Known limitations

Every model limitation and validity range, per CLAUDE.md rule 8. Each entry says what the limitation is, where it applies, how big the effect is if known, and how the software tells the user.

Status: nothing physical is implemented yet. Entries below are placeholders for the sections that will exist; each implemented model adds its own entry in the same change that implements it.

## How to add an entry

| Field            | Content                                                                                         |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| Model            | Function or module affected, and the equation IDs from `docs/equations.md`                      |
| Limitation       | What the model does not capture, or the range outside which it is not valid                     |
| Source statement | What the cited source says about the range, quoted or paraphrased with location                 |
| Effect           | Magnitude of the error if known, or "unknown"                                                   |
| Behaviour        | What the code does at the edge: throws `InvalidInputError`, flags the result, or documents only |
| User-facing      | Where the UI shows this (Phase 3 onwards)                                                       |

| Limitation       | Domain is −5 000 m ≤ Z ≤ 86 000 m geometric altitude. | Behaviour        | throws                                                                                                                                                                                                                                                                                                                      |
| User-facing      | Phase 3: the launch-site altitude field must reject values outside the domain with this message                                                                                                                                                                                                                             |

## Geometry and mass

| Field            | Content                                                                                                                                                                                                                                                                                                   |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Model            | `innerRadius`, GEO-9 (hollow shells)                                                                                                                                                                                                                                                                      |
| Limitation       | The inner surface is the first-order normal offset of the outer surface; it is accurate when the wall is thin compared with the local radius of curvature. Thick walls, or shells on very blunt tips, deviate; the inner radius is clamped at zero near a tip. End faces are open (no end-wall material). |
| Source statement | project convention, D-024                                                                                                                                                                                                                                                                                 |
| Effect           | below 0.01 % of mass for the reference rockets' walls (2 to 3 mm on 25 to 66 mm diameters); unknown for walls comparable to the radius                                                                                                                                                                    |
| Behaviour        | documented                                                                                                                                                                                                                                                                                                |
| User-facing      | Phase 3: warn when wall thickness exceeds a quarter of the base radius                                                                                                                                                                                                                                    |

| Field            | Content                                                                                                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Model            | `finSetMassProperties`, GEO-10                                                                                                                                                                         |
| Limitation       | Fins are thin flat plates: the inertia neglects the thickness direction, fin tabs and fillets are not modelled, and the ½ factor for the longitudinal inertia assumes two or more equally spaced fins. |
| Source statement | thin-plate approximation; Niskanen §4.2.3 p. 64 keeps only two moments of inertia                                                                                                                      |
| Effect           | inertia only; mass and CG are exact for the planform                                                                                                                                                   |
| Behaviour        | documented                                                                                                                                                                                             |
| User-facing      | none in Phase 1                                                                                                                                                                                        |

| Field       | Content                                                                                                                                                                                                                                                                                      |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Model       | `railButtonMassProperties`, `TubeComponent.radialOffset`                                                                                                                                                                                                                                     |
| Limitation  | Rail buttons and launch lugs are treated as point masses (buttons) or parallel-axis offsets (lugs) at their radial position; their own small inertia about their centroid is included only for lugs. Clipped transitions (Niskanen A.7) are not implemented and throw `NotImplementedError`. |
| Effect      | negligible mass (under 1 g on the reference rockets)                                                                                                                                                                                                                                         |
| Behaviour   | documented; clipped transitions throw                                                                                                                                                                                                                                                        |
| User-facing | Phase 3: clipped transition option unavailable                                                                                                                                                                                                                                               |
