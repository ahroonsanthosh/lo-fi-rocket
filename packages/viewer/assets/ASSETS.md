# Viewer assets (plan 3d-0002, D-3D-3)

Every file here is derived from **CC0 (public domain)** assets published by
[Poly Haven](https://polyhaven.com). CC0 needs no attribution; the sources
are listed so that the files can be checked and rebuilt. The scripts are in
`../scripts/` and are not part of the build. All files are illustrative
scenery: none of them is an input to any computation.

| File                                                   | Source (Poly Haven asset)                                                                     | Processing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sky.jpg`                                              | HDRI `kloofendal_48d_partly_cloudy_puresky` (Greg Zaal, Jarod Guest), the 8K "Tonemapped JPG" | Rows from the zenith to 3 % below the horizon, resized to 4096 px wide, JPEG q84 (`prepare_assets.py`)                                                                                                                                                                                                                                                                                                                                                                                                      |
| `sky_light.hdr`                                        | the same HDRI, 1K `.hdr`                                                                      | Box-filtered to 256 × 128, written as Radiance RGBE (`hdr.py`, `prepare_assets.py`). The sun's position in it: u = 0.5952, elevation 47.8° (centroid of the pixels above half the peak)                                                                                                                                                                                                                                                                                                                     |
| `field_diffuse.jpg`, `field_normal.jpg`                | texture `aerial_grass_rock` (2K diffuse, 1K OpenGL normal), 15 m per tile                     | Re-encoded                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `grass_diffuse.jpg`, `grass_normal.jpg`                | texture `leafy_grass` (1K), 2 m per tile                                                      | Re-encoded                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| `trees_colour.webp`, `trees_normal.webp`, `trees.json` | models `fir_tree_01` (three firs), `island_tree_02`, `tree_small_02` (1K glTF)                | Rendered offline in headless Chromium with three.js (`render-billboards.html`, driven by `render_billboards.py`): an orthographic side view under a sky-from-above hemisphere light only (so the crown's self-shadowing is kept but no sun direction is baked in) and a view-space normal pass; cropped to the outline, packed into 256 × 512 cells, edge colours dilated into the transparent area (`atlas.py`). `trees.json` gives each variant's atlas rectangle and its real width and height in metres |
